# Patitas en Ruta

Aplicación web para administrar clientes, perros, agenda de servicios y cobros.

Los datos se guardan en el navegador. Para moverlos entre equipos, descarga un respaldo JSON desde la app y luego impórtalo en el otro equipo. Esta versión no usa sincronización en la nube.

En GitHub Pages, publica los archivos de esta carpeta en la raíz del repositorio. El archivo `index.html` es la página principal.
